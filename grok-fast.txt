### Fallback Logic Validation
The tests validate the routing decisions based on:
- Tenant policies (`force_lite`, `blacklist_backup`, `strict_sl`)
- Circuit breaker state (open/closed)
- Primary model failures (timeouts vs. generic exceptions)

Mocking is used to simulate failures without real network calls. Assertions check which model client's `infer` method is called (or not called) to ensure correct fallback paths.

### Mocking Strategy
- `@patch` decorators mock the `infer` methods of model clients.
- `Mock` objects simulate config with required attributes.
- Circuit breaker state is manipulated by calling `record_failure` to trigger opens.
- Primary failures are simulated by setting `side_effect` on the mock.
